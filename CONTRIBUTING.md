# Contributing

Install dependencies at the package root, then use the sample app:

```sh
yarn
cd sample-app && yarn
```

Start Metro from `sample-app`, and run the app with the usual React Native Android/iOS commands there.

Make sure your code passes TypeScript, lint, and tests:

```sh
yarn typescript
yarn lint
yarn test
```

Open `sample-app/ios/VibesExample.xcworkspace` for iOS native work and `sample-app/android` for Android.
